Boat Data Sheet

RCD Navigator by Blue Peter Marine
Enter your boat data once. Every tool you select is pre-filled, in Annex I.A essential requirement order.

How it works

  1. Tick the tools you need below. Only their fields are shown.
  2. Fill in each field once. The coloured tags show which tools use it.
  3. Click Open on a tool. Its fields are already filled in, marked with a gold edge.
  4. The sheet holds the data of your project only. It stays in this browser on this device. Use Export to keep a copy or send it to Blue Peter Marine.

Which tools do you need?

Listed in essential requirement order. The count shows how many required fields each tool still needs. Tools that do not appear here need no boat data.

    Values the tools calculate are not entered here. Measurements follow ISO 8666 unless the field says otherwise.
