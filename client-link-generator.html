How this works
  1. Each link you create is added to the register above, kept in this browser on this computer.
  2. To remove a client's access, click Remove access, then Download revoked.json and upload it to the root of the bluepetermarine.github.io repository, replacing the old one. Their link stops working within a minute or two.
  3. Restore works the same way: click Restore, download revoked.json again and upload it.
  4. Click Save backup after changes and keep the file somewhere safe. If the browser is cleared, Restore from backup brings the register back.
  5. For clients who already had a link before this register existed, enter the same name, email and project number again. The link comes out identical, so their existing link keeps working and they are added to the register.

This is a light gate, not a hard lock. Anyone holding a client's link and knowing their email and project number can enter. The revoked list on the website holds only one-way codes, never names or emails.
